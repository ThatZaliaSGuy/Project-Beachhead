# Beachhead – Eras of Conquest

**The Refractor-era Battlefields, rebuilt from the ground up.**

**Website:** [thatzaliasguy.github.io/Project-Beachhead](https://thatzaliasguy.github.io/Project-Beachhead/)

Beachhead is an open-source engine that plays your own copies of the classic Battlefield games on
modern technology: faithful first, then better. It reads the original content straight from your
installation and ships engine code only.

This repository hosts the project's website.

## The eras

| Era | Game | Status |
|---|---|---|
| **Beachhead '42** | Battlefield 1942, with The Road to Rome and Secret Weapons of WWII | In development |
| **Beachhead Vietnam** | Battlefield Vietnam | In development |
| **Beachhead Escalation** | Battlefield 2, with Special Forces, Euro Force and Armored Fury | Next |
| **Beachhead Cold Front** | Battlefield 2142, with Northern Strike | Next |

## Classic and Modern

Every era comes in two forms:

- **Classic** preserves the original as closely as possible: the original physics, HUD, menus,
  sound, water, sky and lighting, with every rule recovered from the original game.
- **Modern** layers on a new experience once an era's Classic is complete: a simulated ocean,
  volumetric skies, dynamic weather from clear skies to torrential storms, and destruction.

## Status

Beachhead is in development, and there is no release date yet. Wake Island (Beachhead '42) and
Operation Irving (Beachhead Vietnam) are playable in development builds.

Beachhead is a solo project by **ZALIAS™**, part of the Battlefield 1942 and Battlefield Vietnam
modding community since 2005.
